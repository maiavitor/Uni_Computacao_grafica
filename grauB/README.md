# GrauB

exercicio sobre criação uma cena 3D, a fada na cena está fazendo uma curva de bezier com os pontos gerados automaticamento para um circulo

##controles
- 'W', 'A', 'S', 'D': movimentação da camera no eixo x e z
- 'Mouse' : aponta a direção de observaçao 
- setas do teclado : movimenta o modelo selecionado
- 'M' : Muda o modelo selecionado
- 'X', 'Y', 'Z': rotaciona no eixo selecionado
