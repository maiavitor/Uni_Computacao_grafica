# Tarefa 6 - Curvas Parametricas

exercicio sobre criação de uma curva paramentrica, a fada na cena está fazendo uma curva de bezier com os pontos gerados automaticamento para um circulo

##controles
- 'W', 'A', 'S', 'D': movimentação da camera no eixo x e z
- 'Mouse' : aponta a direção de observaçao
